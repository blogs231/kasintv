How it works

The tool reads text in your browser. It counts characters and lines. Full-width characters receive weight 1. Half-width characters receive weight 0.5. Spaces can be excluded from counts.

Pro tips

  • Use weighted count for mixed CJK and Latin text.
  • Remove extra spaces before measuring content length for publishing.
  • Use line count to estimate paragraphs for scripts and captions.

Use cases

  • SEO meta descriptions and titles
  • Social media captions and posts
  • Manuscript or subtitle length checks
  • Mixed language content length planning

Frequently asked questions

Where does the text go

All processing runs in your browser. No text leaves your device.

How does weighted counting work

Full-width characters count as one unit. Half-width characters count as half a unit. The tool sums weights and shows a decimal result.

Do line breaks count

Yes. The tool counts lines using newline characters. Empty input returns zero.

Is this safe for sensitive text

Yes. All work happens locally. Avoid pasting private data if you prefer.

Which characters are full-width

CJK ideographs, Hiragana, Katakana, Hangul, and full-width punctuation count as full-width.
